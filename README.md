# aicalc – kalkulator kosztów AI

Jednoplikowa aplikacja (edulab) porównująca miesięczny koszt asystenta RAG w trzech opcjach: płatne API modelu, GPU w chmurze i własny serwer. Ceny 10 modeli API sprawdzone 13.09.2026, tokeny liczone z uwzględnieniem języka (polski / angielski). Wszystkie założenia i źródła są w aplikacji pod przyciskiem „Założenia i źródła”.

Na żywo: https://workszop.github.io/aicalc/

Uruchomienie lokalne: otwórz `index.html` w przeglądarce (bez builda, bez serwera).
